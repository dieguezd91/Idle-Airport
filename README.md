# Idle Airport

A 2D idle/incremental airport management game. Passengers queue up, pass through the TSA scanner and wait to board. Earn money, buy stores and upgrades, automate the scanners, and prestige to grow faster.

## Features
- Manual and automatic passenger processing
- Economy, stores and upgrade system
- **Prestige system** built on interfaces (`IPrestigeMultiplierProvider`, `IPrestigeResettable`)
- Passenger **object pooling**
- Presenter/View style UI with feedback ("juice") views
- Large-number formatting for incremental-game scale

## Tech
Unity 6000.0.73f1 · C# (namespace `IdleAirport.GameCore`) · 2D URP · Input System · TextMesh Pro

## Run it
1. Open the repo root with Unity 6000.0.73f1.
2. Open `Assets/Scenes/GameScene.unity` and press Play.
